# HK Birdnest Field Intel: Intelligence Mapping Template
**目標**: 透過「表面聊天」獲取「核心數據」，為後續 Python 分析提供決策維度。

## 📊 1. 跑街情報核心表格 (Field Intel Table)

| 維度 | 資料內容 (Data Point) | 隱藏行規 / 意義 (Industry Logic) | Python 分析用途 |
| :--- | :--- | :--- | :--- |
| **店鋪背景** | 店名、類型 (海味店/藥房/精品) | **階級制**: 傳統海味店最壓價但量大；精品店利潤高但極挑貨。 | 客群分組 (Clustering) |
| **現有玩法** | 他們是「賣斷」還是「寄賣」？ | **風險分擔**: 肯賣斷代表這間店資金足、轉速快；寄賣則代表信任度低。 | 渠道健康度評分 |
| **拿貨來源** | 現由印尼、馬來進貨？還是跟香港大拆商拿？ | **攻防點**: 若跟大拆商拿，我們直接「工廠價」切入極具優勢。 | 競爭對手定位 |
| **價格敏感** | 他們目前的進貨價 $X vs 老闆對我們 $Y 的反應。 | **價格天花板**: 知道對方的「心理關口」，防止報價過低損毛利。 | 市場定價模型 |
| **結款帳期** | **(核心)** 現金、月結 30、還是月結 60+？ | **回款風險**: 香港傳統行規「數期長」是常態。帳期太長則不適合前期小規模合作。 | 財務風險預測 (Cashflow) |
| **產品偏好** | 盞型(大/小)、乾濕度、有沒有刷膠？ | **審美標準**: 香港市場極注重「外貌」。 | 貨品分組策略 |

## 📝 2. 具體 WhatsApp / 語音回報模板

請員工在語音/訊息中，**針對每一間店**回覆以下 5 點（這就是他的 Checklist）：

1.  **[店名/地點]**: (例如：上環 XX 海味)
2.  **[目前玩法]**: (例如：賣斷，拿馬來西亞貨)
3.  **[結款條件]**: (例如：一定要月結 30 天，不肯現金)
4.  **[價格反饋]**: (例如：老闆覺得我們 $7.6/g 算中規中矩，但要求更白一點)
5.  **[老闆個性]**: (例如：豪爽/龜毛/不信任大陸越南貨)

## 💡 3. 您不需要知道行規，這就是您的「行規數據包」

在燕窩貿易中，最容易「死」的地方不是沒生意，而是：
- **死於帳期 (Credit Trap)**: 東西賣出去了，錢三個月後才回來，導致您沒錢跟越南工廠叫下一批貨。
- **死於惡性降價**: 員工為了求成交，隨便答應對方的低價，導致利潤被物流和包裝吃掉。

**您的策略焦點應是：**
「哪間店**肯現金(COD)**、且**不介意越南貨**？」——這才是我們最初 3 個月要主攻的「Trusted Pool」。
至於那些要求「先給一斤試賣、三個月後才給錢」的老牌海味店，前期請一律標記為 **High Risk**。
