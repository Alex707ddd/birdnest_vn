## 1) Visit Workflow
1. Pre-contact by WhatsApp with clear product photos + weight range
2. Shortlist shops that reply with concrete price range
3. On-site visit only for viable targets
4. Same-day written summary after each store

## 2) Mandatory Intel Fields (per store)
- shop_name / location
- business_type (traditional seafood / pharmacy / boutique)
- sourcing_model (upstream source type)
- purchase_mode (cash buyout / consignment)
- settlement_term (COD / 30D / 60D+)
- price_reaction (expensive / fair / attractive)
- product_preference (nest type, dryness, appearance)
- next_action (sample / revisit date)

"Hello 老闆，我哋有一批越南直供頂級白燕盞，無夾膠無漂白，乾度足。\n可否先報你而家收貨價區間？我可即刻發幾張近鏡同重量資料俾你。"

## 5) Printable Checklist (Compact)
- [ ] 店名/地址/聯絡人
- [ ] 店型與現有進貨來源
- [ ] 賣斷或寄賣
- [ ] 結款條件 (COD/30D/60D+)
- [ ] 我方報價與對方反應
- [ ] 對越南貨接受度
- [ ] 下次跟進日期

## 6) Decision Tagging
- `A_CASH_FAST`: COD + acceptable price + positive quality response
- `B_TEST`: needs sample or limited first lot
- `C_RISK`: long settlement cycle / low trust / unstable demand
