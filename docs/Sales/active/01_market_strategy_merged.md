# Market Strategy Merged

## 1) Core Direction
- Go/No-Go: `Go with caution`; run a low-friction B2B-first model, avoid heavy consumer operations at start.
- Main objective: fast cash conversion with controlled compliance risk.

## 2) Channel Priority
1. HK B2B recovery/wholesale (cash-first, fastest turnover)
2. Taiwan trusted-circle route (Uncle/proxy path) for controlled small-scale validation
3. HoReCa / large institutional accounts only after process stability

## 3) Pricing Anchor (Operational)
- Use market-benchmark discount strategy for early trust: roughly 75%-85% of equivalent established retail bands.
- Keep positioning premium enough to avoid "too cheap = fake" perception.
- Weekly review by three buckets:
  - `entry price` (first order conversion)
  - `repeat price` (second order retention)
  - `clearance floor` (inventory defense)

## 4) Compliance Kill Switch
- HK: ensure stable exporter health documentation; if missing, pause scaling.
- TW: if legal importer/operating entity is unresolved, do not scale volume.
- Nitrite/document proof: if no test proof path for target batch, pause outward expansion.

## 5) 30-Day Execution Plan
- Week 1: confirm supply documentation checklist and target SKU set.
- Week 2: run first HK quote cycle with sample photos and weight-based ask.
- Week 3: close first repeatable buyer profile and define settlement terms.
- Week 4: evaluate cashflow cycle, decide continue/hold on scale.

## 6) Stop-Loss Rules
- If no repeatable buyer profile is found within one cycle, reduce to maintenance mode.
- If settlement terms drift to long credit windows beyond tolerance, prioritize cash channels only.
- If margin after logistics/risk buffer drops below threshold, stop expansion and reset pricing.
